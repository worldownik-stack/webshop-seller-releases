# Кабинет продавца — установщики

Здесь лежат выпуски программы продавца для Windows.

**Установка:** откройте [последний релиз](https://github.com/worldownik-stack/webshop-seller-releases/releases/latest)
и скачайте `seller-desktop_…_x64-setup.exe`. При первом запуске Windows может показать
«Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».

**Вход:** напишите боту своего магазина в личку `/login` — он пришлёт адрес магазина
и одноразовый код.

**Обновления** программа ставит сама: она проверяет новую версию раз в 6 часов
и показывает кнопку «Обновить». Ставится только версия, подписанная ключом разработчика.

Файлы сюда кладёт автоматическая сборка; вручную в этом репозитории ничего не меняют.
